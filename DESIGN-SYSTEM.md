# BizNiti 2026 — Design System

## Visual language
Editorial + Swiss structure + modern digital interfaces + restrained glass + kinetic typography.

## Palette
- Paper: #F4F2EC
- Paper 2: #EBE8DF
- Ink: #0B1320
- Blue: #1264FF
- Deep Blue: #083797
- Powder: #DCE7FF
- Lime: #D8F26B
- Peach: #FFB897
- Lavender: #D7CDFC

## Typography
- Display: Georgia / Times-style editorial serif
- UI: system sans stack
- Metadata: system mono stack

## Motion
1. Ambient — slow, low-amplitude movement.
2. Reveal — viewport-triggered entrance.
3. Narrative — pinned horizontal progression.
4. Interaction — state-change motion for controls.

Reduced-motion behavior is supported globally.
